# აგრო-ორნამენტი

**Agro-Ornamenti** is a single-page web application for managing greenhouse-related calculations and records. The goal is to provide intuitive tools that help farmers and agronomists plan and document daily activities directly in the browser.

## Purpose
- Centralize multiple tools in one interface.
- Simplify common calculations and generate printable reports.
- Store user preferences locally for a personalized experience.

## Features
- Responsive navigation menu for quick access to tools.
- Built-in calculators for soil, irrigation, and other tasks.
- AI-powered chat for quick questions.
- Basic user account data stored with localStorage.

## Technologies
- **HTML** and **CSS** for layout and styling.
- **JavaScript** for interactive logic.
- **jsPDF** to export results to PDF.

## How to Run
1. Open the `index.html` file located in the project directory.
2. The file will run directly in your browser with no additional setup.

Everything needed is contained in this single HTML file.

## Key Modules
- **Navigation** – links to each tool section.
- **Calculators** – modules for the main agricultural computations.
- **AI Chat** – a helper bot embedded on the page.
- **localStorage User System** – stores usernames and preferences in the browser.

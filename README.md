# პერინატალური რეაბილიტაციის სისტემა

ვებ-ბაზირებული სისტემა პერინატალური ასფიქსიით დაზარალებული ჩვილების რეაბილიტაციის პროცესის მართვისთვის.

## მახასიათებლები

### 1. პაციენტების მართვა
- **პაციენტის რეგისტრაცია** - სრული დემოგრაფიული და სამედიცინო ინფორმაციის შენახვა
- **პაციენტების სია** - ყველა პაციენტის მოხერხებული ნახვა და ძებნა
- **დეტალური პროფილები** - თითოეული პაციენტის სრული ინფორმაცია

### 2. სამედიცინო შეფასება
- **მოტორული უნარები** - თავის კონტროლი, კიდურების მოძრაობა, მუსკულატურის ტონუსი
- **შემეცნებითი ფუნქციები** - ვიზუალური კონტაქტი, რეაქცია ხმაზე
- **კვების უნარი** - წოვის და ყლაპვის რეფლექსები
- **შეფასებების ისტორია** - ყველა შეფასების შენახვა და ვიზუალიზაცია

### 3. რეაბილიტაციის დაგეგმვა
- **თერაპიის ტიპები**:
  - ფიზიოთერაპია
  - ოკუპაციური თერაპია
  - ლოგოპედია
  - შემეცნებითი თერაპია
  - სენსორული ინტეგრაცია
- **სესიების დაგეგმვა** - თარიღი, დრო, ხანგრძლივობა
- **სესიების მონიტორინგი** - დაგეგმილი და ჩატარებული სესიების აღრიცხვა

### 4. პროგრესის ანალიზი
- **ვიზუალური დიაგრამები** - პროგრესის გრაფიკული ჩვენება
- **სტატისტიკა** - საერთო სტატისტიკური მონაცემები
- **შედარებითი ანალიზი** - პროგრესის შედარება დროში

### 5. მონაცემთა უსაფრთხოება
- **ლოკალური შენახვა** - მონაცემები ინახება მომხმარებლის ბრაუზერში
- **პრივატულობა** - არანაირი მონაცემი არ იგზავნება სერვერზე
- **ექსპორტი/იმპორტი** - მონაცემების დაარქივება და აღდგენა

## ინსტალაცია

### უბრალო გამოყენება
1. ჩამოტვირთეთ პროექტის ფაილები
2. გახსენით `index.html` ბრაუზერში
3. დაიწყეთ მუშაობა!

### ლოკალური სერვერი (არჩევითი)
```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server

# PHP
php -S localhost:8000
```

შემდეგ გადადით: `http://localhost:8000`

## გამოყენება

### 1. ახალი პაციენტის დამატება

1. დააჭირეთ ღილაკს **"ახალი პაციენტი"**
2. შეავსეთ ფორმა:
   - **ძირითადი ინფორმაცია**: სახელი, ID, დაბადების თარიღი, სქესი, წონა, სიმაღლე
   - **კონტაქტური ინფორმაცია**: მშობლის სახელი, ტელეფონი, მისამართი
   - **სამედიცინო ინფორმაცია**: ასფიქსიის სიმძიმე, აპგარის ქულა, დიაგნოზი
   - **რეაბილიტაციის გეგმა**: მიზნები, თერაპიის ტიპები
3. დააჭირეთ **"პაციენტის დამატება"**

### 2. პაციენტის შეფასება

1. **პაციენტების სია** - აირჩიეთ პაციენტი
2. გადადით **"შეფასება"** ტაბზე
3. შეავსეთ შეფასების ფორმა:
   - მოტორული უნარების შეფასება (0-2 ქულა)
   - შემეცნებითი ფუნქციების შეფასება (0-2 ქულა)
   - კვების უნარის შეფასება (0-2 ქულა)
4. დაამატეთ შენიშვნები (არჩევითი)
5. შეინახეთ შეფასება

**შეფასების სისტემა**:
- **0** - არ აქვს / შეზღუდული
- **1** - ნაწილობრივ / საშუალო
- **2** - კარგი / ნორმალური

### 3. სესიების დაგეგმვა

1. პაციენტის პროფილში გადადით **"სესიები"** ტაბზე
2. შეავსეთ ფორმა:
   - აირჩიეთ თერაპიის ტიპი
   - მიუთითეთ თარიღი და დრო
   - განსაზღვრეთ ხანგრძლივობა
   - დაამატეთ შენიშვნები
3. დაგეგმეთ სესია

### 4. პროგრესის მონიტორინგი

1. პაციენტის პროფილში გადადით **"პროგრესი"** ტაბზე
2. ნახეთ ვიზუალური დიაგრამები:
   - მოტორული უნარების პროგრესი
   - შემეცნებითი ფუნქციების პროგრესი
   - კვების უნარის პროგრესი
3. შეადარეთ შედეგები დროის მიხედვით

## მონაცემთა მართვა

### ექსპორტი
მონაცემების დასაარქივებლად გახსენით ბრაუზერის კონსოლი (F12) და აკრიფეთ:
```javascript
exportData()
```

ეს ჩამოტვირთავს JSON ფაილს ყველა მონაცემით.

### იმპორტი
მონაცემების აღსადგენად:
1. გახსენით კონსოლი (F12)
2. შექმენით ფაილის input ელემენტი:
```javascript
const input = document.createElement('input');
input.type = 'file';
input.accept = '.json';
input.onchange = (e) => importData(e.target.files[0]);
input.click();
```

### ტექნოლოგიები
- **HTML5** - სტრუქტურა
- **CSS3** - სტილიზაცია და ანიმაციები
- **Vanilla JavaScript** - ფუნქციონალობა
- **LocalStorage API** - მონაცემთა შენახვა

### ბრაუზერის თავსებადობა
- Chrome/Edge 90+
- Firefox 88+
- Safari 14+
- Opera 76+

სრულად რესპონსიული დიზაინი ყველა მოწყობილობაზე.

## უსაფრთხოება და პრივატულობა

- მონაცემები ინახება **მხოლოდ** თქვენს ბრაუზერში
- არანაირი ინფორმაცია არ იგზავნება სერვერზე
- მონაცემები ხელმისაწვდომია მხოლოდ თქვენი კომპიუტერიდან
- ბრაუზერის მონაცემების გასუფთავებით ყველა ინფორმაცია წაიშლება

## რჩევები და საუკეთესო პრაქტიკები

### რეგულარული შეფასება
- ჩაატარეთ შეფასება **ყოველ კვირას** ან ყოველ **ორ კვირაში**
- შეინახეთ დეტალური შენიშვნები თითოეულ შეფასებაში
- შეადარეთ შედეგები წინა შეფასებებთან

### თერაპიის დაგეგმვა
- დაგეგმეთ სესიები **წინასწარ** მინიმუმ კვირით ადრე
- დაიცავით **რეგულარული განრიგი** საუკეთესო შედეგებისთვის
- დაამატეთ დეტალური შენიშვნები თითოეულ სესიაზე

### მონაცემთა დაცვა
- **ყოველკვირეულად** შექმენით სარეზერვო ასლი
- შეინახეთ ასლები **რამდენიმე ადგილას**
- გამოიყენეთ აღწერითი სახელები ექსპორტირებული ფაილებისთვის

### პროგრესის მონიტორინგი
- რეგულარულად ნახეთ პროგრესის დიაგრამები
- გააანალიზეთ ტენდენციები
- გაიზიარეთ შედეგები მშობლებთან

## მხარდაჭერა

პრობლემების შემთხვევაში:
1. გადატვირთეთ გვერდი (Ctrl+F5)
2. შეამოწმეთ ბრაუზერის კონსოლი შეცდომებისთვის (F12)
3. შექმენით სარეზერვო ასლი მონაცემებისა
4. გაასუფთავეთ ბრაუზერის კეში
